# EchoCopy product images

PNG files with real alpha transparency around their rounded outer edges. Display at their native dimensions or smaller to preserve sharp text.

- `history-dark.png` — 400 × 560; actual ContentView rendered with synthetic sample history.
- `menu-dark.png` — 360 × 203; actual MenuBarHistoryView rendered with the same sample history.
- `settings-dark.png` — 560 × 738; native capture of the General Settings window.

History and menu images contain sample content, not personal clipboard data. No generated UI, desktop backdrop, or background-removal artifacts. Existing README images have not been replaced.
